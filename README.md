# Stuart Carruthers — Voice Over Portfolio

A lightweight static portfolio designed for GitHub Pages.

## Files

- `index.html` — website
- `styles.css` — styling and responsive layout
- `audio/` — place your MP3 demo files here

## Add your audio

Create an `audio` folder and add:

- `story-narration.mp3`
- `character-comedy.mp3`
- `non-fiction.mp3`

You can rename the files, but update the corresponding `<source src="...">` paths in `index.html`.

## Personalise

Before publishing, change:

1. `YOUR-EMAIL@example.com` to your real email address.
2. The biography text if desired.
3. The placeholder portrait panel to your headshot.
4. The audio sample titles/descriptions.
5. Add links to ACX, LinkedIn, Instagram, or other professional profiles if wanted.

## GitHub Pages

1. Create a new GitHub repository, e.g. `voiceover-portfolio`.
2. Upload `index.html`, `styles.css`, `README.md`, and the `audio` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save. GitHub will provide the public Pages URL.

No build system, framework, or server is required.
